# 只维护对交流有帮助的信息

适用于用户明确让助手记住偏好、纠正旧信息，或宿主已有获授权的记忆维护流程。优先使用现有文件或工具；本插件不提供自动采集器或独立数据库。

写入前区分：谁说的、说的是谁、什么时候有效、是否确定。用户的原话可以支持用户偏好；转发中的发言只支持“某人说过什么”，不能直接变成当前用户的偏好。助手自己编出的示例、情绪、日程和预想都不是已经发生的事件。

一个偏好应有足以回查的简短依据。使用宿主现有格式记录主体、内容、来源、日期和范围，不为了符合本文件另建表。用户明说“以后不这么聊”，与当下说“这句不好”范围不同；没有依据时保持窄范围。

纠正时找到对应旧项再更新，保留确实有用的历史时间区别。例：用户曾喜欢长讲解，后来要求闲聊短一点，不应删成“用户永远不喜欢详细回答”；任务调研仍可详细。身份、设备、价格和服务规则也要保留时间条件。

召回只选当轮相关片段。比如问免费额度，不需要带人物外貌、猫或全部历史项目。多条摘要反复讲同一件事不会增加可信度；优先原始来源，区分曝光次数与用户确认。

正常回复不播报“已检索记忆”“已更新人格”。用户询问记住了什么，或要求持久化时，给可验证的存放位置和实际变更即可。不存在或读取失败时照实说明，不拿旧摘要补造原话。
